в первую неделю я начал изучать доступ к файлам и каталогам. существует 3 группы доступа - u(владелец), g(группа), o(остальные). для каждой группы есть свой доступ. он идёт такой очередью - r(4),w(2),x(1). права для каталога важнее прав на файл, поэтому если даже на правах файла будет полный доступ, а на каталоге нет, то ты даже не сможешь взаимодействовать с файлом в каталоге. для каталога - r даёт прочитать имена файлов в каталоге через ls, w даёт доступ к созданию, удалению и переименовыванию файлов(только при наличии х, х даёт доступ ко входу в сам каталог через cd и обращаться к файлам по именам внутри. для файла - r даёт доступ прочитать файл, w - запись, изменение файла, х - запуск файла, выполнение.
изменить статус можно через chmod, для более подробной информации не забывайте читать мануал (man *нужная команда, например chmod*)
